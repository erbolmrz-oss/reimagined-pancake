# 🎨 Центр Красок #1 — Telegram AI-ассистент

Telegram-бот с AI-ассистентом для интернет-магазина [centr-krasok.kz](https://centr-krasok.kz/)

## Как работает

Пользователь пишет вопрос в Telegram → бот отвечает на основе базы знаний о компании через AI (Claude).

## Возможности

- 💬 Свободный диалог без команд
- 🧠 Отвечает только по теме магазина (без галлюцинаций)
- 🌍 Поддержка русского, казахского, английского языков
- 🕐 Помнит контекст диалога (последние 10 сообщений)
- 📦 Информация о товарах, брендах, доставке, акциях

## Технологии

- Python 3.10+
- python-telegram-bot
- OpenRouter API (Claude AI)

## Запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Создать `.env` файл с токенами
3. Запустить: `python bot1.py`

## Переменные окружения
TELEGRAM_TOKEN=your_telegram_token
OPENROUTER_API_KEY=your_openrouter_key
